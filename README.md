# Onfy Health Hubs

Editable, responsive starting point for a series of health-product verticals.

## Start locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Edit content

- `app.js` — categories, icons and product cards
- `index.html` — page sections and copy
- `styles.css` — visual design and responsive rules

The category selector becomes a horizontal touch slider on mobile, while the product carousel remains visible and swipeable.
